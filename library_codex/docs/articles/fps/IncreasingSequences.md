# 上下限付き単調増加列の数え上げ

## 主な機能

各位置で選べる整数の範囲を指定し、広義単調増加な列が何通りあるかを数える。

$$
\mathrm{lower}_i \le x_i < \mathrm{upper}_i,
\qquad x_0\le x_1\le\cdots\le x_{N-1}.
$$

同じ値が続いてもよい。`lower`と`upper`自身が単調でなくても使える。値を全探索する用途ではなく、条件を満たす列の個数だけが必要なときに使う。

既定の法998244353では、上下限を単調性で補正した後の値域幅をWとして、`O((N+W) log²(N+W+2))`時間、`O(N+W)`メモリ。小さい場合は直接DPを使う。

## 使い方

```python
from library_codex.fps.IncreasingSequences import count_increasing_sequences

answer = count_increasing_sequences([0, 1], [2, 3])
print(answer)
```

返り値は`4`。数えている列は`[0, 1]`、`[0, 2]`、`[1, 1]`、`[1, 2]`。`upper`は含まないので、2番目の値に3は選べない。

- 解がない場合は`0`を返す。
- 空列は1通り。返り値はこれを`mod`で割った余り。
- 下限・上限は負数でもよい。両方へ同じ整数を足しても答えは変わらない。
- 返り値は整数1個であり、実際の列や各位置の選び方は返さない。

## 仕組み

各要素を選ぶ位置を横移動の高さと考えると、上下の境界を越えない格子経路の数え上げになる。領域を階段状の部分と長方形へ分け、長方形を通る経路数を二項係数の畳み込みでまとめて計算する。分割統治は明示的なstackで処理し、Pythonの再帰は使わない。

長方形の一辺から別の辺へ移る計算では、必要な中央係数だけを循環畳み込みから取り出す。不要な前後の係数のためにNTTを大きくしない。

## 注意点

- 厳密増加を数える場合は、位置iの両方の境界からiを引いて渡す。
- 998244353で高速経路を使う場合は`N + W + 2 <= 2の22乗`が必要。超える場合は`ValueError`。長さ1または値域幅1は直接求める。
- それ以外の正の`mod`も指定できるが、`O(NW)`時間のDPになる。合成数の法も使える。
- 値そのものが大きくても、共通のoffsetは除く。ただし上下限の差Wが大きい場合のメモリは省略できない。
- `lower`と`upper`の長さが違う場合、または`mod <= 0`は`ValueError`。
