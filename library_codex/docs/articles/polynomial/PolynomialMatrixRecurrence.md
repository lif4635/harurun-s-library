# 一次式の行列で進む漸化式

## 主な機能

状態ベクトルを、時刻の一次式を要素に持つ行列で繰り返し更新します。1回ずつ進める代わりに、連続する遷移の積を多項式としてまとめ、多点評価してから適用します。

$$
v_{t+1}=\frac{(A+tB)v_t}{c+td},\qquad t=0,\ldots,T-1.
$$

入力は初期ベクトル、定数行列A、一次係数行列B、分母の係数c・d、遷移回数Tです。modは素数とし、途中の分母がすべて非零である必要があります。

## 使い方

```python
from library_codex.polynomial.PolynomialMatrixRecurrence import linear_matrix_recurrence

assert linear_matrix_recurrence([1], [[1]], [[1]], (1, 0), 5) == [120]
assert linear_matrix_recurrence([0, 1], [[0, 1], [1, 1]], [[0, 0], [0, 0]], (1, 0), 10) == [55, 89]
```

- 1つ目は各stepでt+1を掛けるため、5の階乗です。
- 2つ目はFibonacci数列の連続2項です。行列が定数なら、通常の行列累乗や線形漸化式の方が適しています。
- 返り値は遷移後の状態を初期値と同じ成分順に並べたlistです。各要素はmodの余りです。

## 計算量

次元をr、分割幅をB=ceil(sqrt(T))、B項の畳み込み時間をM(B)とすると、O(r³ M(B)log(B+2))時間、O(r²B+B log(B+2))空間が目安です。Tが64以下なら直接計算します。次元が大きい場合には向きません。

行列の積は後の遷移を左へ掛けます。順序を入れ替えられるという仮定はありません。

## 注意点

- 途中で分母の逆元がなければValueErrorです。ゼロになった後の再開や極限は扱いません。
- 素数判定はしません。998244353以外では、畳み込みの実装により定数倍が変わります。
- 通常の定数係数漸化式や、小さいTでは専用実装の方が速い場合があります。
- 初期ベクトルと行列は変更しません。
