# 素数の法で多項式を因数分解する

係数を素数で割った余りとして扱い、多項式をそれ以上分解できないモニック多項式の積に分ける。

## 主な機能

- `factor_polynomial(polynomial, mod, seed)` — 既約因子の係数列を返す。同じ因子が複数回現れる場合は、その回数だけ並ぶ。
- 法が2の場合や、微分すると零多項式になる場合にも対応する。
- 次数をN、多項式積の時間をM(N)とすると、期待 `O(N M(N) log(mod) + N M(N) log(N+1))` を上限の目安とする。剰余計算を繰り返す方式で、因子の次数によって実行時間が変わる。

## 使い方

```python
from library_codex.polynomial.PolynomialFactorization import factor_polynomial

factors = factor_polynomial([2, 0, 4, 1], mod=5)
assert factors == [[1, 1], [1, 1], [2, 1]]
```

上の入力は、法5で次の積になる。

$$
2+4x^2+x^3=(x+1)^2(x+2).
$$

- `factors[i][j]`: i番目の因子の次数jの係数。定数項から順に並ぶ。
- `factors`の順序: 次数が小さい順。同じ次数では係数列の辞書順。
- 各因子の最高次係数: 1。入力の最高次係数が1でなければ、それで割って正規化した多項式を分解する。

## 注意点

- `mod`は素数を指定する。素数判定は行わない。
- 非零定数だけの入力では、その定数を要素とする係数列を一つ返す。例: `[3]`に対して`[[3]]`。
- 零多項式では`ValueError`。末尾の0は取り除く。
- `seed`は分割に使う乱数を固定する。同じ実行環境・seedなら再現でき、入力配列は変更しない。
- 因数分解ではなく根だけが必要なら、`PolynomialRoots`の`polynomial_roots`を使う。
