# 64bit整数の畳み込み

`convolution_u64(a, b)`は、整数の係数列を畳み込み、各係数を2の64乗で割った余りにする。unsigned 64bitの加算・乗算で桁あふれする場合と同じ結果を返す。

## 主な機能

- `convolution_u64(first, second)` — 昇べき順の係数列2本を受け取るfunction。浮動小数点を使わず、整数として正確に計算する。
- 負数や64bitに収まらない整数も渡せる。入力の各値は先に2の64乗で割った余りへ正規化する。
- 結果の長さをLとして`O(L log(L+2))`時間、`O(L)`追加メモリ。片方が32要素以下なら直接計算する。

返り値の各要素は次の値。

$$
c_k=\left(\sum_{i+j=k}a_i b_j\right)\bmod 2^{64}.
$$

## 使い方

```python
from library_codex.convolution.Convolution64 import convolution_u64

print(convolution_u64([1, 2, 3], [4, 5]))
print(convolution_u64([-1, 1], [1, 1]))
```

出力はそれぞれ`[4, 13, 22, 15]`、`[18446744073709551615, 0, 1]`。

- `result[k]`: 添字の和がkになる入力要素同士の積和。
- 長さ: 両入力が空でなければ`len(first)+len(second)-1`。末尾が0でも切り詰めない。
- 要素: 0以上、2の64乗未満の整数。負の符号付き整数には変換しない。
- 空の入力: 片方でも空なら空list。

## 仕組み

5つの素数を法としてNTTを行い、中国剰余定理で積和を非負整数として復元してから、下位64bitを取り出す。入力の長さに上限を設け、復元が一意になることを保証する。

$$
2^{20}(2^{64}-1)^2
<998244353\cdot1012924417\cdot1224736769\cdot754974721\cdot469762049.
$$

## 注意点

- 両入力が空でない場合、結果の長さは2の21乗以下。それを超えると`ValueError`。
- 素数の法でのFPS演算には`NTT998`などを使う。この法では偶数の逆元を作れない。
- XOR畳み込みや有限体F₂⁶⁴上の畳み込みではない。添字は通常の足し算、係数は整数の足し算・掛け算で扱う。
- 入力は変更しない。iterable一般ではなく、`len`を取得できる整数列を渡す。
