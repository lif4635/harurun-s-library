# 区間転倒数の一括計算

## 主な機能

配列と問い合わせ区間をまとめて渡し、それぞれの転倒数を求める。転倒とは、区間内の左側の要素が右側の要素より大きい組のこと。同じ値の組は数えない。

すべての区間が先に分かるなら、この`range_inversions`を使う。内部で問い合わせをMo順に並べ替えて処理するが、返り値は渡した順に戻す。配列長N・問い合わせ数Qに対してメモリはO(N+Q)。

前の答えを見て次の区間を決める場合は、別モジュールの`StaticRangeInversions`を使う。そちらは都度問い合わせできる一方、O(N sqrt(N))の前計算メモリが必要になる。

## 使い方

```python
from library_codex.range_query.OfflineRangeInversions import range_inversions

a = [3, 1, 2, 2, 0]
queries = [(0, 5), (1, 4), (2, 5), (2, 2)]
answers = range_inversions(a, queries)
```

`answers`は`[7, 0, 2, 0]`。

- `answers[0]`は配列全体の転倒数7。
- `answers[1]`は半開区間 `[1, 4)` の`[1, 2, 2]`に対する0。同じ値の2同士は数えない。
- `answers[2]`は半開区間 `[2, 5)` の`[2, 2, 0]`に対する2。
- `answers[3]`は空区間に対する0。

各答えは、対象区間だけを昇順にするための隣接交換の最小回数でもある。問い合わせkの両端をleft、rightとすると、返り値の定義は次のとおり。

$$
\mathrm{answers}[k]=\#\{(i,j)\mid \mathrm{left}\le i<j<\mathrm{right},\ a_i>a_j\}.
$$

## 仕組みと計算量

値を座標圧縮し、現在の区間の頻度をBITで管理する。区間の左端・右端を一つ動かすとき、追加・削除する値より小さい要素または大きい要素の個数を数え、転倒数を更新する。左右の端では足す組の向きが違い、同じ値は含めない。

Moの分割幅は問い合わせ数に合わせて選ぶ。時間は期待O((N sqrt(Q+1)+Q) log(N+2) + Q log(Q+2))、メモリはO(N+Q)。比較・hashをO(1)とした計算量で、前者のlogはBIT操作、後者は問い合わせの整列に由来する。

## 注意点

- 入力の配列・問い合わせのlistは変更しない。
- 配列更新を挟むことはできない。更新後に呼び直すと、前計算もやり直す。
- 範囲は常に半開区間。空区間は0、問い合わせが空なら`[]`を返す。
- 値は互いに大小比較でき、hashできるものを渡す。比較結果が変わるオブジェクトやNaNは対象外。
- 一つの区間しか調べない場合、配列全体の転倒数だけを求める既存の`inversion_count`も使える。
