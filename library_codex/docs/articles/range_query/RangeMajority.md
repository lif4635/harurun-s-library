# 点更新できる区間過半数検索

## 主な機能

配列の半開区間 `[left, right)` から、長さの半分を超えて現れる値とその回数を求める。ちょうど半分の場合や空区間では、過半数は存在しない。

- `majority(left, right)`: 過半数があれば `(値, 出現回数)`、なければ `None`。
- `count(value, left, right)`: 指定した値の出現回数。
- `set(index, value)`: 1要素の置き換え。

配列長をNとして構築はO(N)時間・領域。更新しない場合、問い合わせはO(log(N+1))。初めて値を変えるときにO(N)の準備を行い、その後の更新・問い合わせは期待O(log(N+1))、最悪O(N)。hashと等値比較をO(1)とした計算量。

最も多く現れる値を必ず返す構造ではない。過半数に届かなくても最頻値が必要なら、変更しない配列には `StaticRangeMode` を使う。

## 使い方

```python
table = RangeMajority([1, 2, 1, 2, 1])
assert table.majority(0, 5) == (1, 3)
assert table.majority(0, 4) is None
table.set(1, 1)
assert table.majority(0, 4) == (1, 3)
assert table.count(2, 0, 5) == 1
assert table.tolist() == [1, 1, 1, 2, 1]
```

- 1回目は1が5要素中3回現れるため、`(1, 3)`。
- 2回目は1も2も4要素中2回で、過半数ではない。
- 更新後は現在の列に対して回数を数える。

## 仕組み

異なる値を1個ずつ打ち消しても、もとの区間に過半数の値があれば最後の候補に残る。この候補と残り個数をセグ木で管理し、候補が実際に何回現れるかを別に数えて判定する。打ち消し後の個数は出現回数ではない。また、候補の合成は一般の結合的なモノイドではない。

更新前は値ごとの出現位置をソート済み配列で持つ。初回の更新で、出現位置を管理するtreapに切り替える。配列の添字をそのままノード番号に使い、左右の子・親・部分木サイズを平坦な配列へ保存する。更新のたびにノードobjectを作らず、同じN個のノードを再利用する。

## 注意点

- 要素は辞書のキーとして使える値。整数の大小関係は使わないため、文字列やtupleでもよい。
- `None`も要素として使える。`(None, 3)`は「値Noneが3回」、返り値そのものが`None`なら「過半数なし」。
- treapの優先度だけを乱数で決める。答えの正しさは乱数に依存しない。
- `tolist()`は現在の列の浅いコピー。元の入力listや返されたlistを書き換えても、管理中の列は変わらない。
