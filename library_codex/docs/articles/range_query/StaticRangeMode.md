# 変更しない配列の区間最頻値

## 主な機能

配列の半開区間から、最も多く現れる値とその出現回数を求める。同じ回数の値が複数ある場合は、その区間で最初に現れる値を返す。

- `mode(left, right)`: 最頻値と回数を返す。
- `count(value, left, right)`: 指定した値の出現回数を返す。
- 要素は辞書のキーとして使える値。整数だけでなく文字列やtupleも扱える。

配列長をN、ブロック幅をBとすると、構築は期待O(N ceil(N/B))時間、保持領域はO(N + ceil(N/B)²)。最頻値の取得はO(B)、指定値の回数は期待O(log(N+1))。hash・等値比較をO(1)とした計算量で、既定のBは約sqrt(N)。

問い合わせをまとめて渡す必要はない。構築後、前の答えから次の区間を決める使い方もできる。

## 使い方

```python
table = StaticRangeMode([5, 2, 2, 5, 7])
assert table.mode(0, 4) == (5, 2)
assert table.mode(1, 5) == (2, 2)
assert table.count(5, 0, 5) == 2
assert table.mode(3, 3) == (None, 0)
```

- `mode(0, 4)`: 5と2がともに2回現れる。区間の先頭にある5を返す。
- `mode(1, 5)`: 2だけが2回現れるため、2を返す。
- 空の区間では `(None, 0)`。

## 仕組み

完全に含まれるブロックの最頻値・回数・最初の位置を前計算する。問い合わせでは両端の短い部分だけを調べる。

各位置について「同じ値の何回目の出現か」を持つため、ある候補が現在の最頻回数を超えるかは、出現位置の配列を直接引いて判定できる。候補ごとの二分探索は行わない。完全ブロック部分から増える最頻回数は、両端で追加した要素数以下なので、走査全体もO(B)になる。

## 注意点

- 構築後の要素変更には対応しない。元の入力listはコピーするが、要素自身を後から変更しない。
- 区間は半開区間。右端は含まない。
- `block_size`は正整数。小さくすると問い合わせは短くなるが、構築時間と保持領域が増える。
- `tolist()`は入力順の新しいlistを返す。
