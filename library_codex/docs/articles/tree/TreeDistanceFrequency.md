# 木の距離ごとの頂点対数

重みなし木について、頂点間距離がそれぞれ何通りあるかをまとめて数える。

## 主な機能

`tree_distance_counts(tree)` は、距離を添字、頂点対の個数を値とする整数の配列を返す。同じ2頂点の順番を入れ替えても1組として数える。個数はmodを取らずに返す。

時間 O(N log² N)、追加メモリ O(N)。すべての頂点対を列挙したり、各頂点からBFSを行ったりせずに距離分布を得られる。

## 使い方

```python
from library_codex.tree.TreeDistanceFrequency import tree_distance_counts

tree = [[1], [0, 2], [1, 3], [2]]
counts = tree_distance_counts(tree)
assert counts == [0, 3, 2, 1]
assert tree_distance_counts(tree, include_same=True) == [4, 3, 2, 1]
assert sum(counts[1:3]) == 5
```

- `counts[d]`: 距離dの頂点対数。この例では距離1が3組、距離2が2組、距離3が1組。
- `counts[0]`: 通常は0。`include_same=True`なら、各頂点と自分自身のN組を数える。
- 配列の長さ: 木の直径+1。存在しない長い距離の0は省く。空の木は`[]`、1頂点なら`[0]`または`[1]`。

距離が配列長以上なら、その距離の頂点対は0組として扱う。

## 仕組み

重心を通る頂点対を距離ヒストグラムの畳み込みで数え、同じ枝に含まれる対を除く。処理済みの部分の経路やヒストグラムは保持しない。

畳み込み係数の上限に応じてNTTの法を選ぶ。1つの法で足りる場合はそれだけを使い、必要なら複数の法から整数値を復元する。小さいヒストグラムは整数のまま直接計算する。

## 注意点

- `tree[v]`には隣接頂点の整数番号を並べる。無向辺は両側へ入れる。
- 重み付きの距離や一般グラフには使えない。
- 入力の隣接リストは変更しない。再帰を使わないので、長いパス状の木も扱える。
