# 木の距離区間への加算

## 主な機能

ある頂点からの距離が指定した半開区間に入るすべての頂点へ、同じ値を加える。更新後の値を頂点ごとに取得できる。

- `add(vertex, lower, upper, delta)`: 距離が `lower` 以上 `upper` 未満の頂点へ加算する。
- `get(vertex)`: 指定した頂点の現在値を返す。
- 初期構築は時間・領域ともに O(N log N)。加算・取得は1回 O(log² N)。

木の辺に重みは持たせず、距離は通る辺の本数で数える。点への加算と距離範囲の合計が必要なら `CentroidDistanceFenwick` を使う。

## 使い方

頂点0から順に一直線につながる4頂点の木。

```python
tree = [[1], [0, 2], [1, 3], [2]]
solver = CentroidDistanceAdd(tree, [10, 20, 30, 40])
solver.add(1, 1, 3, 5)
assert solver.tolist() == [15, 20, 35, 45]
assert solver.get(2) == 35
solver.add(2, 0, 1, -10)
assert solver.get(2) == 25
```

- 最初の更新対象は頂点0・2・3。頂点1自身は距離0なので対象外。
- `get(2)` は頂点2の初期値30に加算5を反映した35を返す。
- 距離範囲 `[0, 1)` を指定すれば、指定頂点だけを更新できる。

## 注意点

- 距離の上限は含まない。`upper=None` は上限なし。
- 更新範囲が空なら何も変更しない。
- 辺の追加・削除や、辺の重み付き距離には対応しない。
- `tolist()` は全頂点の現在値を頂点番号順に返す。O(N log² N)かかるため、確認用に使う。
