# 木の経路に沿った一次関数の合成和

各頂点に整数値、各辺に一次関数を持つ木を管理する。頂点や辺を更新しながら、指定した頂点へ全頂点の値を集めた総和を求める。

## 主な機能

- `set`で頂点値、`set_edge`で辺の一次関数を置換する。
- `query(root)`で、各頂点から`root`へ向かう経路の順に一次関数を適用し、その結果を全頂点について足す。`root`自身の値も1回含む。
- 木の形は固定。問い合わせごとに集める先を変えられる。
- 構築O(N log N)、更新・問い合わせはそれぞれO(log N)、保持する整数はO(N)個。法での整数演算をO(1)とする。

辺の一次関数は両方向で同じ。辺を逆向きに通っても逆関数にはしない。

## 使い方

```python
from library_codex.tree.TreePathCompositeSum import TreePathCompositeSum

tree = TreePathCompositeSum([1, 2, 3], [(0, 1, 2, 1), (1, 2, 3, 4)])
at_zero = tree.query(0)
at_one = tree.query(1)
tree.set(2, 5)
after_value = tree.query(0)
tree.set_edge(0, 1, 0)
after_edge = tree.query(0)
```

- 辺の組は`(u, v, b, c)`で、`u`と`v`を結び、通過する値を`b*x+c`へ写す。
- `at_zero`は33。頂点0の1、頂点1からの5、頂点2からの27を足す。
- 頂点2から0へは、先に`3*x+4`、次に`2*x+1`を適用する。
- `at_one`は18。頂点0からの3、頂点1の2、頂点2からの13を足す。
- `after_value`は45。頂点2の値だけを5へ置き換えた結果。
- `after_edge`は22。入力の0番目の辺を恒等関数へ置き換えた結果。

返り値は既定の法998244353で割った余りの整数。法を変える場合は構築時に`mod`を指定する。

## 合成の順番

頂点vからrootまでの辺を通過順に並べ、対応する一次関数をfの添字0からk−1で表す。vが総和へ寄与する値は次のとおり。

$$
f_{k-1}(f_{k-2}(\cdots f_0(a_v)\cdots)).
$$

経路が空なら元の頂点値をそのまま足す。途中で求めるのは経路上の頂点値の和ではなく、始点の値に辺の関数を合成した結果。

## 仕組み

Static Top Treeで木を小さな部分へ分け、順方向・逆方向の合成と総和を保持する。更新時は影響する部分だけを計算し直し、問い合わせ時は指定頂点へ向かう向きで合流させる。

内部の各部分は整数IDと平坦な配列で管理する。再帰や逆元計算は使わない。

## 注意点

- `values`の長さは1以上。`edges`は閉路のない連結な木で、長さはN−1。
- `set_edge`の添字は構築時に渡した辺の順番。辺の両端や木の形は変更できない。
- 係数0・負数・合成数の法にも対応する。頂点値と係数は常に`mod`で割った余りとして保持する。
- `tolist()`は現在の頂点値、`edges()`は現在の`(u, v, b, c)`を入力順に並べた新しいlist。各根への問い合わせ結果を並べる関数ではない。
