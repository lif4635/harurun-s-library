# 群の差を保つ Union-Find

## 主な機能

頂点ごとの未知の値に対して、「頂点 `b` の値は、頂点 `a` の値に `d` を右から掛けたもの」という制約を追加する。既存の制約と矛盾する追加は拒否し、同じ連結成分にある2頂点の差を求められる。

加算・剰余加算のほか、可逆行列の積や順列の合成など、掛ける順番で結果が変わる群にも使える。整数の加算だけなら `WeightedUnionFind` が使える。

群の積を `op`、逆元を `inv`、単位元を `unit` として渡す。`merge(a, b, d)` が追加する制約と、`diff(a, b)` が返す値は次のとおり。

$$
x_b=x_a\cdot d,\qquad \operatorname{diff}(a,b)=x_a^{-1}\cdot x_b.
$$

構築は時間・領域ともに O(N)。更新・問い合わせは償却 O(α(N)) 回の群演算で行う。群演算そのもののコストは別に掛かる。

## 使い方

法7での差を保つ例。

```python
uf = PotentialUnionFind(3, lambda a, b: (a + b) % 7, lambda a: -a % 7, 0)
uf.merge(0, 1, 5)
uf.merge(1, 2, 4)
print(uf.diff(0, 2))
print(uf.merge(0, 2, 3))
print(uf.diff(2, 0))
```

- 1つ目の出力は `2`。頂点2と頂点0の差は `(5 + 4) % 7`。
- 2つ目は `False`。差を3にする制約は矛盾するため追加されない。
- 3つ目は `5`。差の向きを逆にすると `-2 % 7`。

## 注意点

- `op(a, b)` はその順番で積を計算する。結合則・単位元・逆元が成立する演算を渡す。
- 群の要素は変更しない値として扱う。`op`・`inv` は入力を書き換えず、返された値も後から変更しない。
- 同じ群の要素は `==` で等しい必要がある。剰余なら各演算の返り値を同じ範囲へ正規化する。
- `diff` は未接続なら `None`。頂点の絶対的な値は定めない。
- `weight(v)` は現在の代表頂点から `v` への差。代表頂点が変われば変化する。
- `tolist()` は頂点順に `(代表頂点, その代表頂点からの差)` を並べる。内部の辺の重みではない。
