# 各辺を含む4-cycleの数

4つの相異なる頂点を一周する閉路について、入力の各辺が何通りの閉路に含まれるかを数える。平行な辺は別々の選択肢として数え、対角線があってもよい。

## 主な機能

- `count_c4_per_edge(n, edges, weight=None)` — 各辺の答えを、入力順のlistで返すfunction。
- 重みを渡すと、対象辺以外の3辺の重みの積を合計する。重みを省略すると単純な個数になる。
- 平行辺をまとめた辺数をUとすると、通常の整数ではO(N log(N+1) + M + U sqrt(U))時間、O(N+M)メモリ。

## 使い方

```python
from library_codex.graph_enumeration.CountC4PerEdge import count_c4_per_edge

edges = [(0, 1), (0, 1), (1, 2), (2, 3), (3, 0)]
assert count_c4_per_edge(4, edges) == [1, 1, 2, 2, 2]
assert count_c4_per_edge(4, edges, [2, -2, 1, 1, 1]) == [1, 1, 0, 0, 0]
```

- result[i]はedges[i]を含む閉路の値。平行な2辺にもそれぞれ結果がある。
- 重み付きでは固定した辺自身の重みは掛けない。上の例では2と-2の打ち消しが、他の3辺の答えに現れる。

## 仕組み

平行辺の重みを足し合わせ、単純グラフの計算に帰着する。次数順で頂点を取り除き、同じ終点へ向かう長さ2の道を組み合わせる。最後に元の辺番号へ答えを戻す。

## 注意点

- 自己辺は受け付けない。
- 同じ無向辺を逆向きに書いた場合も平行辺として数える。無向隣接listの両方向をそのままedgesへ渡さない。
- 重みが大きい場合は整数の積・加算にも時間がかかる。0や負の重みは使える。
