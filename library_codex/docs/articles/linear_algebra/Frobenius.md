# 行列の累乗・累乗和・多項式代入

## 主な機能

素数modのN行N列の行列Aを一度分解し、大きな指数の累乗、累乗の和、多項式の代入を求めます。行列全体が必要な場合と、初期状態の列ベクトルを遷移させた結果だけが必要な場合の両方を扱います。

`Frobenius(A)`の構築は、998244353のようにNより十分大きい素数では期待O(N³)。構築後の`pow(K)`・`sum(K)`はO(N³ + N² log(K+1))時間です。第2引数にベクトルを渡すと、行列全体を作らずO(N²(1+log(K+1)))時間・O(N)追加空間で求めます。

同じAなら指数・初期状態・多項式を変えて分解を使い回せます。行列全体を返す場合だけ、基底を戻すO(N³)の行列積が毎回必要です。`eval(c, v)`は係数の個数をLとしてO(N²+NL)、`eval(c)`はO(N³+NL)時間です。

## 使い方

```python
from library_codex.linear_algebra.Frobenius import Frobenius

a = [[1, 1], [1, 0]]
f = Frobenius(a)
assert f.pow(5) == [[8, 5], [5, 3]]
assert f.pow(0) == [[1, 0], [0, 1]]
assert f.pow(5, [1, 0]) == [8, 5]
assert f.sum(5) == [[12, 7], [7, 5]]
assert f.sum(5, [1, 0]) == [12, 7]
assert f.eval([2, 3, 1]) == [[7, 4], [4, 3]]
assert f.eval([2, 3, 1], [1, 0]) == [7, 4]
assert f.tolist() == a
```

- `pow(K)`はN行N列の新しいlist。`result[i][j]`がAのK乗の第i行・第j列です。`pow(K, v)`は長さNの新しいlistで、K回遷移した状態の第i成分が`result[i]`です。
- `sum(K)`は0乗からK-1乗までの和です。K乗は含みません。`sum(K, v)`は初期状態を含むK時刻分の状態の総和を返します。
- `eval(c)`は`c[i]`をi乗の係数として代入した行列です。`eval(c, v)`はその行列をvに掛けた結果です。上の例では係数`[2, 3, 1]`から次の行列を作ります。

$$
2I+3A+A^2
$$

- すべての成分はmod未満の非負整数です。引数も返り値も行ベクトルではなく列ベクトルとして扱います。
- `tolist()`は累乗結果ではなく、構築時のAをmodで正規化したコピーです。
- 元のAや返されたlistを書き換えても、保存した分解は変わりません。

## 時刻をまとめて数える

次の列を初期状態vとして、更新をK回繰り返した結果が`pow(K, v)`です。

$$
v_{t+1}=Av_t,\qquad v_0=v
$$

`sum(K, v)`は次の総和です。たとえば隣接行列を使うなら、長さ0以上K未満の歩道による到達回数をまとめられます。Aの第i行・第j列はjからiへの遷移係数です。

$$
\sum_{t=0}^{K-1}A^tv
$$

半開区間[L, R)の時刻だけを足す場合は、`sum(R, v)`と`sum(L, v)`を成分ごとに引き、modで正規化します。

```python
from library_codex.linear_algebra.Frobenius import Frobenius

f = Frobenius([[1, 1], [1, 0]])
lo = f.sum(2, [1, 0])
hi = f.sum(5, [1, 0])
assert [(y - x) % 998244353 for x, y in zip(lo, hi)] == [10, 6]
```

## 仕組み

基底を変え、行列を多項式に対応する小さなブロックへ分けます。

$$
A=P\,\operatorname{diag}(C_1,\ldots,C_r)P^{-1}
$$

各ブロックでは、多項式で割った余りとしてxのK乗を求めます。最後に基底を戻します。

$$
A^K=P\,\operatorname{diag}(C_1^K,\ldots,C_r^K)P^{-1}
$$

ベクトル指定時は、まずvを分解の座標へ移し、各ブロックの多項式乗算と剰余で作用を計算します。最後も行列とベクトルの積だけなので、行列同士の積を使いません。

累乗和は、ブロックの多項式をgとして、次の余りを計算してからx-1で割ります。分子は必ず割り切れ、A-Iの逆行列は不要です。

$$
\frac{\bigl(x^K\bmod((x-1)g(x))\bigr)-1}{x-1}
$$

乱数は基底の選択だけに使います。ブロックを独立に分離できない試行は捨ててやり直し、失敗した分解から答えを返すことはありません。

## 注意点

- modは素数を渡してください。素数判定は行いません。合成数modや、min-plusなど別の演算には使えません。
- 特異行列、零行列、同じ固有値の繰り返しも扱います。行列A自体の逆行列は必要ありません。
- `sum(0)`は零行列、`sum(0, v)`は零ベクトルです。`sum(1, v)`はvの正規化コピーです。単位行列や固有値1を含む行列でも累乗和を計算できます。
- `eval([])`は零行列です。係数は定数項から並べ、負数・末尾の0も渡せます。
- `seed`を指定すると基底選択を再現できます。省略時は毎回異なる選択を使います。
- 構築は1試行O(N³)、最大`trials`回です。全試行が失敗すると`ArithmeticError`になります。小さい素数では再試行が増えることがあり、Nに対して十分大きい素数での期待時間と区別してください。
- 指数が小さい場合や、順列行列・対角行列のように疎さを保つ場合は、既存の`Matrix.matrix_power`の方が速いことがあります。通常版は変更していません。
- 多項式を一度だけベクトルへ作用させる場合は、行列とベクトルの積を繰り返すHorner法が速い場合があります。`eval(c, v)`は構築済みの分解を他の照会と共有するときに向きます。
- Pythonの整数演算を定数時間とした計算量です。非常に大きいmodでは多倍長整数の費用もかかります。
