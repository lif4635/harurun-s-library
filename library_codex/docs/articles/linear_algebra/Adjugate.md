# 余因子行列

素数を法とする正方行列から、余因子を転置して並べた行列を求める。逆行列が存在しない場合も使える。

## 主な機能

`adjugate(matrix, mod)`は、N×Nの行列を行ごとのlistで受け取り、同じ大きさの行列を返す。返り値をB、入力をAとすると、

$$
B_{i,j}=(-1)^{i+j}\det A_{\widehat{j},\widehat{i}},
\qquad AB=BA=(\det A)I \pmod{\mathrm{mod}}
$$

ここで小行列は、Aの**j行目とi列目**を取り除いたもの。行と列の順序が逆になる点に注意する。

- 逆行列が存在する場合: Bは逆行列に行列式を掛けたもの。
- 階数がN−1の場合: Bは零行列ではない。Bの各列はAを掛けると零になるので、同次方程式の解を取り出せる。
- 階数がN−2以下の場合: Bは零行列。

時間は`O(N³ + N log mod)`、追加領域は`O(N²)`。整数四則演算を定数時間として数える。入力の行列は変更しない。

## 使い方

```python
from library_codex.linear_algebra.Adjugate import adjugate

a = [[1, 2], [3, 4]]
b = adjugate(a, 7)
assert b == [[4, 5], [4, 1]]

a = [[1, 2], [2, 4]]
b = adjugate(a, 7)
assert b == [[4, 5], [5, 1]]
x = [row[0] for row in b]
assert all(sum(u * v for u, v in zip(row, x)) % 7 == 0 for row in a)
```

- `b[i][j]`: 余因子行列のi行j列。値は0以上mod未満。
- `x`: 後半の例では`[4, 5]`。特異行列でも余因子行列は求まり、この列から非零の解が得られる。

## 仕組み

単位行列を右に並べ、行基本変形を一度行う。正則なら右側から逆行列と行列式を回収する。階数がN−1なら、消去結果から左右の零空間のベクトルと倍率を求め、その外積で全要素を復元する。余因子ごとの行列式計算や乱数による補助行列は使わない。

## 注意点

- `mod`は素数を指定する。素数判定は行わない。
- 空行列には`[]`、1×1の行列には元の値が0でも`[[1]]`を返す。
- 正方行列でなければ`ValueError`。
- 階数N−1でも、特定の列は零になることがある。同次方程式の非零解が欲しい場合は、非零の列を選ぶ。
