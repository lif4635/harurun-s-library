# 区間ソートと区間積

キーと値の組を並べた配列に対し、区間の昇順・降順ソート、1要素の置換、区間内の値の集約を行う。ソートすると値もキーと一緒に移動する。

## 主な機能

- 区間を何度も並べ替え、その途中で和・最小値・関数合成などを求められる。
- `prod(left, right)`は、半開区間`[left, right)`を現在の左から右への順序で集約する。演算は結合則と単位元を満たせばよく、交換則は不要。
- キーは互いに異なる整数。構築はO(N)、取得・置換・区間積は期待O(log N)。ソートを含むQ操作全体は期待O((N+Q) log²(N+2))、保持する要素・集約値の個数はO(N)。ここでは演算`op`と値の保持をO(1)とする。
- ソート1回が必ずO(log N)で終わるわけではない。まだ統合していない区間をまとめる呼出しでは、その分の処理が発生する。

## 使い方

```python
from library_codex.sequence_structure.SortableArray import SortableArray

data = SortableArray(lambda a, b: a + b, "", [(3, "C"), (1, "A"), (2, "B")])
data.sort(0, 3)
ascending = data.tolist()
data.sort(0, 2, reverse=True)
word = data.prod(0, 3)
data.set(1, 4, "D")
item = data.get(1)
```

- `ascending`は`[(1, "A"), (2, "B"), (3, "C")]`。
- `word`は`"BAC"`。降順ソートした区間内では、値を集約する順も逆になる。
- `item`は`(4, "D")`。`set`は現在位置1の要素を置換するだけで、配列全体を自動ソートしない。
- `get`は`(key, value)`、`prod`はキーを除いた値の集約結果を返す。

関数合成なら`op(f, g)`を「fを適用してからgを適用する合成」として渡す。たとえば一次関数を`(a, b)`で持つ場合は次のように書ける。

```python
mod = 998244353

def compose(f, g):
    a, b = f
    c, d = g
    return a * c % mod, (b * c + d) % mod

data = SortableArray(compose, (1, 0), [(5, (2, 1)), (2, (3, 4))])
a, b = data.prod(0, 2)
answer = (a * 10 + b) % mod
```

`answer`は67。2倍して1を足し、その結果を3倍して4を足す。

## 仕組み

配列をソート済みの区間に分け、各区間のキーをtreapで持つ。ソートでは対象の区間を統合し、昇順・降順の向きだけを切り替える。各木には順方向と逆方向の集約値を保持し、区間の境界と区間間の積はFastSetとSegTreeで管理する。

各要素には整数IDを1つ割り当て、子・部分木サイズ・集約値を平坦な配列へ置く。分割や再ソートで要素用ノードを増やさず、`set`も同じ領域を再利用する。再帰は使わない。

## 注意点

- `get`・`set`の添字はキーではなく、ソート後の現在位置。
- 重複キーは`ValueError`。`set`で同じ要素のキーをそのまま使うことはできる。
- 空区間の積は単位元。空配列も構築できる。
- `op`は引数を書き換えない関数を渡す。値のコピーは浅いコピーで、格納した可変オブジェクトを外から変更しない。
- treapの疑似乱数による平衡化に依存する期待計算量で、最悪時間の保証ではない。`op`がT時間なら、集約を伴う計算量にTを掛ける。文字列連結の例は順序の説明用で、長い文字列ではO(1)演算にならない。
