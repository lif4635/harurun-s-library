# 凸多角形の各頂点からの最遠点

## 主な機能

凸多角形の頂点を周回順に渡すと、各頂点から最も遠い頂点の番号をまとめて返す。時間・追加領域はともに `O(N)`。

点集合全体から最遠の一組だけを求める `FurthestPair` とは異なり、頂点ごとに答えが得られる。

## 使い方

```python
from library_codex.geometry.ConvexFurthest import furthest_neighbors

points = [(0, 0), (4, 0), (4, 3), (0, 3)]
answer = furthest_neighbors(points)
print(answer)
```

出力は `[2, 3, 0, 1]`。

- `answer[i]`: `points[i]` から最も遠い頂点の、入力内での添字。
- 最遠の頂点が複数ある場合は、そのうち一つを返す。
- 入力の配列は変更しない。空なら `[]`、1点なら `[0]` を返す。

## 仕組み

頂点列を二周分並べた距離行列で、各行の最大値の位置を SMAWK で求める。全ての距離を保存せず、比較に必要なものだけ計算する。

凸多角形でも、一つの頂点からの距離が周回順に単峰になるとは限らない。距離が増える間だけ次の頂点へ進む方法では正しく求められない。

## 注意点

- 3点以上では、相異なる狭義凸多角形の頂点を時計回りまたは反時計回りに渡す。この前提の検査や凸包の作成は行わない。
- 未整列の点集合なら、先に凸包を作る。返る番号は凸包上の添字であり、元の点集合の添字ではない。
- 整数座標では距離の二乗を整数で比較する。平方根や浮動小数点数への変換は使わない。
