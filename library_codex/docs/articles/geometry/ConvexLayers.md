# 凸包の層分解

点集合から凸包の境界を取り除く操作を繰り返し、外側から何層目にある点かを調べる。

## 主な機能

- `onion_depth(points)` は、各入力点の層番号を入力順に返す。最外層は `0`、その一つ内側は `1`。
- `convex_layers(points)` は、層ごとの境界点を外側から順に返す。各層の点列は辞書順最小点から反時計回りに並ぶ。

既定では凸包の辺の途中にある点も同じ層へ含める。点の削除に合わせて凸包を更新し、全体の時間は `O(N log² N)`、追加空間は `O(N)`。各層で残った全点から凸包を作り直す必要はない。

## 使い方

```python
from library_codex.geometry.ConvexLayers import convex_layers, onion_depth

points = [(0, 0), (4, 0), (4, 4), (0, 4), (2, 2), (2, 0)]
depth = onion_depth(points)
layers = convex_layers(points)
```

- `depth` は `[0, 0, 0, 0, 1, 0]`。中央の `(2, 2)` だけが内側に残る。
- `layers[0]` は `[(0, 0), (2, 0), (4, 0), (4, 4), (0, 4)]`。辺上の `(2, 0)` も含む。
- `layers[1]` は `[(2, 2)]`。

## 辺の途中の点を残す場合

`keep_collinear=False` を指定すると、各層で凸包の頂点だけを除く。

```python
depth = onion_depth(points, keep_collinear=False)
```

この例では `[0, 0, 0, 0, 1, 1]`。辺の途中にあった `(2, 0)` は、四隅を除いた後の層へ入る。この設定では同じ境界点を複数回調べることがあり、最悪時間は `O(N² log N)` になる。

## 注意点

- 同じ座標の点は一つの幾何点として扱う。`onion_depth` の結果は入力と同じ長さで、重複点には同じ番号を返す。
- 全点が一直線上にある場合、既定では全点が最外層に入る。`False` では両端から二点ずつ除く。
- 一層が全て共線点なら、その点列は辞書順。始点を末尾へ重ねない。
- 整数座標なら判定は厳密。浮動小数点ではほぼ共線な配置の丸め誤差に注意する。
