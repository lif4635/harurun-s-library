# 最近点対

平面上の点から、距離が最小になる異なる2点を求めます。

## 主な機能

- 入力した点の添字2つと、距離の二乗を返します。
- 同じ距離の組が複数あるときは、添字の組が辞書順最小のものを返します。重複点も扱えます。
- 時間計算量は O(N log N)、追加メモリは O(N)。再帰は使いません。

## 使い方

```python
from library_codex.geometry.ClosestPair import closest_pair

points = [(0, 0), (5, 0), (6, 1), (20, 20)]
first, second, distance_squared = closest_pair(points)
```

- `first = 1`、`second = 2`: 選ばれた点は `points[1]` と `points[2]`。
- `distance_squared = 2`: 平方根を取る前の距離。整数座標では整数のまま比較できます。

## 仕組み

x座標順に分割し、各区間をy座標順に併合します。分割境界の近くにある点だけを比較します。見つかっている最小距離を全区間で共有し、それより遠い点を除外します。

座標・添字・併合用領域は配列に分けて保持し、区間ごとの辞書は作りません。

## 注意点

- 点が2個未満の場合は `ValueError` になります。
- 入力は変更しません。各点は `(x, y)` または `[x, y]` で渡せます。
- 浮動小数点座標では、その型の丸め誤差が距離比較にも反映されます。
