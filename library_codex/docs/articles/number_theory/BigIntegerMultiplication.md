# 巨大整数の乗算

10進・16進の整数を文字列のまま受け取り、積も文字列で返す。符号付きの数や、数十万桁以上の入力を扱える。

## 主な機能

- `multiply_decimal`は10進、`multiply_hex`は16進の乗算を行う。
- 正負の符号と先頭の0を受け付け、返り値では不要な符号・先頭0を取り除く。
- 入力2文字列の長さの合計をNとして、時間はO(N log(N+1))、追加メモリはO(N)。短い入力や片方だけ短い入力では小さい計算へ切り替える。

## 使い方

```python
from library_codex.number_theory.BigIntegerMultiplication import multiply_decimal, multiply_hex

decimal = multiply_decimal("-00123", "+00456")
hexadecimal = multiply_hex("ab", "10")
zero = multiply_decimal("-000", "123")
```

- `decimal`は`"-56088"`。整数ではなく10進の文字列。
- `hexadecimal`は`"AB0"`。16進の数字は大文字で返す。
- `zero`は`"0"`。`"-0"`にはならない。

## 仕組み

10進は5桁、16進は4桁ずつに分け、2つの素数を法とするNTTで畳み込む。中国剰余定理で各係数を整数へ戻し、繰り上がりを処理する。浮動小数点の丸め誤差はない。

## 注意点

- 入力は`str`。`+`・`-`は先頭だけに置ける。16進の入力は小文字でもよい。
- 空白、`_`、`0x`接頭辞、全角数字、空文字列は`ValueError`になる。
- NTTを使う場合、桁分割後の2配列の長さの合計から1を引いた値は`2**23`以下である必要がある。超える場合は`ValueError`。たとえば10進は各200万桁、16進は各160万桁の2整数を扱える。
- Pythonの整数文字列変換の上限設定は変更しない。巨大な10進文字列全体を`int`へ変換する処理も不要。
