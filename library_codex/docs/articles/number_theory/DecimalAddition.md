# 大きな10進整数を文字列のまま加算する

数十万桁・数百万桁の整数を、整数全体へ変換せずに足し合わせる。

## 主な機能

`add_decimal(first, second)`は符号付き10進文字列を2つ受け取り、和を10進文字列で返す。負数同士や、符号の異なる数の加算にも使える。

入力の総文字数をLとして、時間・追加領域ともに`O(L)`。再帰や外部ライブラリは使わない。

通常の大きさの整数ならPythonの`int`と`+`で十分。この関数は、巨大な10進文字列を`int`へ変換し、最後に`str`へ戻す時間を避けたいときに使う。16進文字列では標準の`int(text, 16)`と`format(value, "X")`を使えるため、同じ処理を包む別APIは置かない。

## 使い方

```python
from library_codex.number_theory.DecimalAddition import add_decimal

assert add_decimal("99999999999999999999", "1") == "100000000000000000000"
assert add_decimal("-100000000000000000000", "3") == "-99999999999999999997"
assert add_decimal("+0012", "-0012") == "0"
```

返り値には先頭の余分な0や`+`を付けない。負数だけに`-`が付き、ゼロは常に`"0"`。

## 仕組み

末尾から9桁ずつ取り出し、繰り上がり・繰り下がりを処理する。巨大な入力全体を多倍長整数へ変換せず、各9桁だけを`int`へ変換する。両方とも18桁以内の場合だけ、通常の整数加算を使う。

## 注意点

- 入力は`str`。先頭の`+`・`-`とASCIIの数字だけを受け付ける。
- 空文字列、空白、小数点、桁区切り、全角数字は`ValueError`。
- 文字列を返す関数なので、そのまま掛け算などの整数演算へ渡す用途ではない。
