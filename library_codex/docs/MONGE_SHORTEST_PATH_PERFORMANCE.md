# k辺最短路の計測

2026-09-07、WSL Ubuntu / PyPy 3.10.14 (7.3.16)。各実装を小さい入力で3回実行後、対象入力を3回実行した中央値。並列実行はしない。旧実装の辺数別DPを比較用スクリプト内に残している。

| 重み | N | k | 旧実装 | 新実装 |
| --- | ---: | ---: | ---: | ---: |
| `(j-i)**2` | 2000 | 1000 | 0.635秒 | 0.00171秒 |
| `(j-i)**2` | 8000 | 4000 | 11.605秒 | 0.00529秒 |
| `(j-i)**2 + ((j*7919)%2001-1000)` | 2000 | 1000 | 0.776秒 | 0.00586秒 |

二乗コストの答えは区間長をできるだけ均等にした閉形式、偏りのあるコストは旧実装と比較した。倍率は入力に依存し、一般的な速度保証ではない。小さいkや巨大な整数では辺数別DPへ切り替えるため、これほどの差は出ない。

```sh
pypy3 library_codex/benchmarks/monge_shortest_paths.py
pypy3 library_codex/benchmarks/monge_shortest_paths.py --sizes 2000 --biased
pypy3 -m pytest -q library_codex/verify/optimization/test_monge_shortest_paths.py
```

専用テストはMonge行列を生成し、全てのkの答えを三重ループのDPと照合する。負の重み、ペナルティの正負、同点で辺数が飛ぶ場合、巨大整数、非整数用DP、境界値、重み関数の呼出し回数、配布用コードの単独実行を検査する。
