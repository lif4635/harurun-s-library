# 編集距離・疎な微分方程式の比較

2026-11-16。PyPy 7.3.16、WSL2、CPU 2に固定。各方式を新しいprocessで5回ずつ実行し、順番を入れ替えた。ライブラリ計算部分の時間と、起動込みの時間・最大RSSを別々に保存している。CPUを他processから隔離せず、メモリ上限も強制していない。

測定scriptは `benchmarks/reference_expansion.py`、全試行・入力hash・答えhash・実装hashは[JSON](../../verify/library_checker/benchmarks/comparisons/reference-expansion.json)。Nim/C++の参照実装との同言語性能比較ではない。

## 編集距離

旧版と同じ2行DPを比較器として保持している。値の生成は測定外、ビットマスクの構築は測定内。

| 入力 | 2行DP中央値 | ビット並列中央値 | DP / ビット並列 | 最大RSS: DP / ビット並列 |
| --- | ---: | ---: | ---: | ---: |
| 24要素・4種類、2000回 | 0.032661秒 | 0.019677秒 | 1.66倍 | 74.7 / 74.6 MiB |
| 4000要素・4種類 | 0.206308秒 | 0.020259秒 | 10.18倍 | 82.6 / 74.8 MiB |
| 4000種類の異なる整数 | 0.131576秒 | 0.020326秒 | 6.47倍 | 84.5 / 75.9 MiB |
| 4000要素・2箇所だけ異なる列 | 0.163984秒 | 0.016964秒 | 9.67倍 | 84.5 / 74.7 MiB |
| 長さ16000と16 | 0.008215秒 | 0.004285秒 | 1.92倍 | 74.8 / 74.5 MiB |

2箇所だけ異なる列に上限8の対角帯DPを使うと0.025920秒・75.3 MiBで、ビット並列より遅かった。bounded版は小さい上限だけ調べたいときの選択肢であり、常に速いとはしない。自動的には切り替えない。

hash不能な要素には従来のDPを使う。無条件にビット並列へ変えて対応可能な入力を減らすことはしない。

## 疎な微分方程式

比較する列は次。

$$F(x)=\exp\left(\frac{x}{1-x}\right),\qquad (1-x)^2F'(x)=F(x),\qquad F(0)=1.$$

既存の `fps998` の `fps_div` と `fps_exp` を順に呼ぶ方法と、`sparse_differential([1], [1,-2,1], N)` を比較した。既存API側の疎密自動選択は無効にしていない。

| 係数数 | 既存API中央値 | differential中央値 | 既存 / differential | 最大RSS: 既存 / differential |
| --- | ---: | ---: | ---: | ---: |
| 8192 | 0.049321秒 | 0.007997秒 | 6.17倍 | 77.3 / 74.7 MiB |
| 65536 | 0.147404秒 | 0.015917秒 | 9.26倍 | 87.9 / 76.9 MiB |

A、Bが密な場合の優位性は示していない。既存の密なFPS演算をこの方法へ置き換えず、既存の疎FPS moduleへ用途を追加する。

## Dirichlet演算の再測定

古くなっていた2問は、公式全件検証で遅かった3ケースを各5回、公式checkerで答えを確認した。今回はCPU固定なし、時間は起動・JIT・入出力込み。

| 問題 | ケース数 | 最大中央値 | 最大RSS |
| --- | ---: | ---: | ---: |
| dirichlet_convolution_and_prefix_sums | 3 / 24 | 22.076秒 | 447.7 MiB |
| dirichlet_inverse_and_prefix_sums | 3 / 25 | 16.870秒 | 327.8 MiB |

以前の古いsourceの測定13.340秒・10.786秒より遅い。今回はsourceと環境の両方が以前と同一ではないため、原因や速度比は断定しない。10秒未満を達成したとは扱わない。最新記録のsource hashは現在の提出用コードと一致する。今回、公式全24・25ケースを再実行したわけではない。

## 再実行

リポジトリ直下で、測定役はLinux CPython、実行対象はPyPyを指定する。

```sh
/usr/bin/python3 library_codex/benchmarks/reference_expansion.py --python /path/to/pypy3 --repeat 5 --cpu 2
```

`--cpu` は使用できるCPU番号へ合わせる。記録には実際のCPU affinityと環境が入る。比較中は他の重い検査を同時に走らせない。
