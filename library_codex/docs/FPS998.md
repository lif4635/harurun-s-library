# FPS 998244353 の設計と保証範囲

`library_codex.fps998`は、競技プログラミングで最も頻繁に使う
`998244353`固定の形式的冪級数を、汎用mod経路から分離して提供します。

## 設計

- `mod`引数、原始根探索、CRT、動的なNTT objectを実行経路へ含めない。
- 係数列は昇べき順の`list[int]`とし、`a[i]`を$x^i$の係数とする。
- 公開FPS演算は入力listを変更せず、新しいlistを返す。
- `ntt`、`intt`、`ntt2d`、`intt2d`だけは入力を破壊的に変換する。
- 逆NTTは公開APIの`intt`で必ず正規化する。未正規化逆変換はmodule内部だけで使う。
- FPS998のbundleには`NTT998.py`だけを含め、汎用`NTT.py`を依存へ入れない。
- 頻繁に書くAPIは`fps_inv`、`fps_log`、`fps_exp`のような短く定着した名前を正規名とし、同じ処理の長いaliasを作らない。
- `fps_compositional_inv`はLagrange反転をpower coefficient、log、expへ帰着し、$O(N\log^2 N)$で計算する。

## 高速化の選択

- 密な`fps_inv`、`fps_log`、`fps_exp`、`fps_pow`、`fps_sqrt`は、998244353固定のradix-4 NTT経路を使う。
- 非零項が少ない入力では、`fps_inv`（160項以下）、`fps_div`・`fps_log`（200項以下）、`fps_exp`（320項以下）、`fps_pow`・`fps_sqrt`（32項以下）が自動で疎な漸化式へ切り替わる。必要な係数数を$N$、非零項数を$K$として$O(NK)$。閾値はLibrary Checker向け実装を参考にしつつ、PyPyで密なNTT経路との交差を計測して演算ごとに決めている。利用側で別APIを選ぶ必要はない。
- `fps_compose`は降下時に得た分母のNTT結果を保持し、上昇時に同じ変換をやり直さない。
- `power_projection`とBostan--Moriは、分子と分母のNTTを同じ段で共有する。各段の変換回数を6回から4回へ減らしている。
- 小さい畳み込みと小さい合成では、NTTの準備時間を避けて単純計算へ切り替える。

## 機能保証

過去の`library/convolution/FPS.py`が扱っていた公開機能は、過去のsourceを
実行時依存や互換wrapperとして残さず、次の新実装で保証します。

| 機能 | module | 公開API |
| --- | --- | --- |
| 順NTT・正規化済み逆NTT | `convolution/NTT998.py` | `ntt`, `intt` |
| 係数畳み込み・二乗 | `convolution/NTT998.py` | `multiply`, `square` |
| 正規化・加減算 | `fps998/FPS.py` | `shrink`, `fps_add`, `fps_sub`, `fps_neg` |
| 微分・積分・評価 | `fps998/FPS.py` | `fps_diff`, `fps_integral`, `fps_eval` |
| 逆元・対数・指数・冪・平方根 | `fps998/FPS.py` | `fps_inv`, `fps_log`, `fps_exp`, `fps_pow`, `fps_sqrt` |
| FPSの商（指定次数で打ち切り） | `fps998/FPS.py` | `fps_div` |
| 多項式の商・余り | `polynomial/PolynomialDivision998.py` | `poly_div`, `poly_mod`, `poly_divmod` |
| Taylor shift・一括積 | `fps998/FPS.py` | `taylor_shift`, `fps_product` |
| FPS合成・合成逆 | `fps998/Composition.py` | `fps_compose`, `fps_compositional_inv` |
| power projection | `fps998/PowerProjection.py` | `power_projection`, `power_coefficient` |
| 有理FPSの第$n$項・線形漸化式 | `fps998/LinearRecurrence.py` | `bostan_mori`, `linear_recurrence_nth`, `berlekamp_massey`, `nth_term` |
| 部分集合・多重集合の重さ別個数 | `fps998/SubsetSum.py` | `subset_sum`, `multiset_sum` |
| 2次元NTT・2変数係数畳み込み | `fps998/NTT2D.py` | `ntt2d`, `intt2d`, `multiply2d` |

この表は特定の古いsignatureを維持する互換表ではなく、FPS998系列が失っては
ならない機能一覧です。対応APIの削除や意味の変更はtestとcatalog検査で検出します。

## 検証

- NTTのround tripを各2冪長で確認する。
- 全FPS演算を小さい入力の単純解とrandomized比較する。
- 合成・power projection・線形漸化式・部分集合母関数・2次元畳み込みを単純解と比較する。
- standalone bundleが汎用NTT、CRT、原始根探索を含まないことを検査する。
- PyPyで`multiply`、`fps_inv`、`fps_exp`を継続計測する。

主要演算を同じ決定的入力で個別に計測するには、次を使います。

```bash
pypy3 library_codex/tools/benchmark_fps998_core.py --size 4096 --repeat 5
```

`--only compose`や`--only linear_recurrence`を付けると、1項目だけ再計測できます。
疎な漸化式と密なNTT経路の交差を再確認する場合は、次を使います。

```bash
pypy3 library_codex/tools/benchmark_fps998_core.py --size 4096 --repeat 3 --sparse-sweep
```

Library Checker の最大制約、上位 C++ / PyPy 提出との演算別比較、NTT 回数、変更前後の実測は [FPS998_PERFORMANCE.md](FPS998_PERFORMANCE.md) にまとめています。
